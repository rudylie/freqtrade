# Strategy Library

- `approved/`: strategy code that passed research review.
- `candidates/`: promising strategy code not yet promoted to dry-run.
- `rejected/`: failed or abandoned strategies with notes.
- `archived/`: old snapshots and historical variants.

Do not keep runnable strategy files directly in this directory. Put them in one of the status folders above.

Legacy imports from the previous `user_data/archived-strategies/` layout are kept under `archived/imported-legacy-archive-*`.
